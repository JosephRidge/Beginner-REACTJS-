# Web Development with React: Curriculum Tracks

Three 8-week, project-based courses that take learners from their current level to a published React app. Each track has week-by-week plans, a styling or code example, a build-then-improve-the-UI-with-AI session, an assessment rubric, and a links table.

| Track | Who it is for | Styling | Folder |
| --- | --- | --- | --- |
| Plain CSS | Absolute beginners | CSS files, Flexbox, Grid, CSS variables | [plain-css-track](beginner-with-plain-css.md) |
| Tailwind | Absolute beginners | Core CSS first, then Tailwind utility classes | [tailwind-track](beginner-with-tailwind.md) |
| Mid-level | Learners who know JavaScript and have heard of React | Tailwind (optional) | [mid-level-track](mid-level.md) |

## Choosing a track

- Pick **Plain CSS** or **Tailwind** if learners are new to coding. Both teach the same content and differ only in how React work is styled, so choose one and keep the whole cohort on it.
- Pick **Mid-level** only after the Week 1 diagnostic shows learners are comfortable with JavaScript functions, arrays, objects, async/await, and Git. Learners who struggle should join a beginner track.
- All tracks assume 4 sessions a week of 3 hours each (about 96 hours); adjust the pacing to your schedule.

## Shared ideas

- Each track is structured by strands, sub-strands, and specific learning outcomes, with a four-level rating (Exceeds, Meets, Approaches, Below).
- Every week ends with a deliverable pushed to GitHub, and the capstone README states the problem, the solution, and the decisions made.
- The AI session teaches learners to write the logic themselves, use an assistant only for the UI, and check everything it suggests.
